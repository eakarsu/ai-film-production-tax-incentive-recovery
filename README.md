# Film Production Tax Incentive Recovery

Calculate and document jurisdictional film incentives from qualified local labor and production expenditure.

**Primary buyer:** Film studios, producers, and production finance teams. **Evidence:** incentive rules, budgets, payroll, vendors, residency, qualified spend, financing, audits, applications, certificates, transfers, and cash.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Jurisdiction incentive library
- Production entity registry
- Budget cost ingestion
- Payroll residency validation
- Vendor location validation
- Qualified spend classification
- Related-party control
- Financing source treatment
- Minimum spend threshold
- Credit rebate calculation
- Audit sample workbench
- Application package
- Certificate tracking
- Credit transfer monetization
- Production jurisdiction analytics

Run `./start.sh`, then open <http://127.0.0.1:4739>. API: `5739`.
